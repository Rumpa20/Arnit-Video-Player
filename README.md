# Arnit Video Player

A modern Android video player with a cinematic purple interface.

## Version
**2.3.0**

## Features
- Online and offline video playback
- Grid and list library views
- Full-screen playback with swipe gestures
- Picture-in-Picture support
- Subtitle and audio track selection
- Playback speed controls
- Equalizer and bass boost controls
- Playback history and favorites
- Search and folder filtering
- Multi-select video actions
- Share multiple videos
- Video details and bulk delete with confirmation
- Sorting by name, date, duration, and file size
- Light and dark themes

## Build
Open the project in an Android-compatible IDE and run the `:app:assembleRelease` Gradle task.

## Release signing
Keep your release keystore and `keystore.properties` private. Never commit `.jks` files, passwords, or signing credentials to this repository. Use `keystore.properties.example` as a template.
